# Lab docs site

Web tĩnh (GitHub Pages) đọc tài liệu lab trên điện thoại.

- `python build.py` — build lại `docs/` từ `D:\Downloads\tài liệu` và `D:\Downloads\Devops` (bỏ `Lab`)
- `python server.py` / `start.bat` — chạy server trong mạng LAN (port 8000)
- GitHub Pages: Settings → Pages → Branch `main`, folder `/docs`
